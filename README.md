# Lantern Atelier

An original, offline spot-the-difference game. Wander through three illustrated evening scenes and find six small changes in each. Click either panel, use `1`–`6` to mark a discovery, press `H` for a gentle hint, or use the arrow keys to change scenes. Progress is saved locally.

Run with any static HTTP server from this directory, serving `game/` as its root. The hand-in driver is `node main.ts` (Node 22); set `MAKEFUN_OUTPUT_DIR` to a local output directory when running outside the grader.
